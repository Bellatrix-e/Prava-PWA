IMPORTANTE: va pubblicata su un indirizzo HTTPS (non basta aprire index.html
dal telefono o dal computer). Il modo gratuito piu' semplice e' GitHub Pages:

1. Crea un account su github.com
2. New repository -> nome "libreria" -> Public -> Create
3. "uploading an existing file" -> trascina TUTTO il contenuto di questa cartella
   (le cartelle docs, icons, pdfjs comprese) -> Commit changes
4. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, / (root) -> Save
5. Dopo 1-2 minuti il link sara' https://TUONOME.github.io/libreria/

SUL TELEFONO
  Android (Chrome): apri il link -> menu (tre puntini) -> "Installa app"
  iPhone (Safari):  apri il link -> Condividi -> "Aggiungi a schermata Home"
  Poi apri l'app dalla Home -> "Scarica la libreria".
  Prova la modalita' aereo: deve funzionare lo stesso.

AGGIORNARE I PDF
  Sostituisci i file in docs/, aggiungili a library.json e aumenta "version".
